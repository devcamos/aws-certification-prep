# labs — Cloud Practitioner

Light console practice that helped the ideas stick.

## Sandbox checklist

- [ ] Create / confirm a sandbox AWS account (never use production)
- [ ] Switch Region and explain why Region choice matters
- [ ] Create an IAM user with MFA; avoid using root day to day
- [ ] Create a Budget and open Cost Explorer
- [ ] Launch and stop a tiny EC2 instance (or use Free Tier carefully)
- [ ] Create an S3 bucket; enable encryption and block public access
- [ ] Look at CloudWatch metrics for something you started

## One-page design exercise

Write one page covering:

- Chosen Region and why
- Main service families (compute, storage, database, network)
- Shared responsibility split for the app
- Cost controls (budget, tagging idea)
- Which support plan would fit a learner account
