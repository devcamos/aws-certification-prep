# AWS Certification Prep

My path through AWS certifications. Each cert gets its own folder with the same layout.

```
aws-certification-prep/
├── cloud-practitioner/   # CLF-C02 - passed
│   ├── docs/             # domain notes
│   ├── how-to-book/      # booking / badge record
│   ├── prep/             # checklist + refresh
│   └── labs/             # console practice ideas
└── ai-practitioner/      # AIF-C01 - booked Fri 13 Nov 2026
    ├── docs/             # domains + capability cards
    ├── how-to-book/      # OnVUE booking details
    ├── prep/             # study plan, practice, weak spots
    └── labs/             # hands-on exercises + capstone
```

## Progress

| Cert | Status |
|------|--------|
| AWS Certified Cloud Practitioner (CLF-C02) | Passed, badge earned Feb 2025 |
| AWS Certified AI Practitioner (AIF-C01) | Exam booked for 13 Nov 2026 |

## What goes in each folder

- **docs** — notes and domain summaries
- **how-to-book** — how to book the exam and the booking details
- **prep** — study plan, practice questions, weak spots
- **labs** — hands-on exercises
