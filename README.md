# AWS Certification Prep

My path through AWS certifications. Each cert gets its own folder with the same layout.

This repo only keeps structure, booking status, and **links to official AWS content**. It does not store study notes or practice questions.

```
aws-certification-prep/
├── cloud-practitioner/   # CLF-C02 - passed
│   ├── docs/
│   ├── how-to-book/
│   ├── prep/
│   └── labs/
└── ai-practitioner/      # AIF-C01 - booked
    ├── docs/
    ├── how-to-book/
    ├── prep/
    └── labs/
```

## Progress

| Cert | Status |
|------|--------|
| AWS Certified Cloud Practitioner (CLF-C02) | Passed, badge earned Feb 2025 |

## What goes in each folder

- **docs** — links to official exam guides and AWS docs
- **how-to-book** — booking details for this sitting
- **prep** — links to official AWS exam prep (Skill Builder)
- **labs** — links to official AWS hands-on labs and workshops
